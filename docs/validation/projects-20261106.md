# ZCode 桌面项目列表读取验证

日期：2026-11-06。仓库：HuBoZhi/zcode_mcp；本地目录：`G:/Coding/Github/zcode_mcp`。

## 实现

- 保留已安装实例使用的 Windows 入口、非 C 盘运行目录、stdio 关闭和 provider revision 兼容修改。
- 增加 `zcode_projects` MCP 工具，返回桌面保存的本地项目 ID、名称、主目录、所有根目录及来源。
- 数据来自桌面 `tasks-index.sqlite` 的 `projects`、`project_roots` 表，排除删除与远程记录，不拿历史会话或最近目录代替项目。
- 源数据库和 WAL 仅复制，SQLite 只打开 D/G 盘快照。复制前后检查文件状态，最多三次，持续变化时明确报错。快照在 finally 中清理。
- 无需安装或启动 app-server，不创建会话，不调用模型，不读取凭据。
- `ZCODE_PROJECTS_DB` 可覆盖桌面数据库路径。此路径独立于任务执行器的 `ZCODE_STORAGE_DIR`。
- Windows 快照父目录必须已存在且实际位于非 C 盘；目录联接落到 C 盘会拒绝。
